ProductSiteCMS V0.5 修正版

【今回の修正】
・左サイドバー型の管理画面を廃止
・公開サイトのHTMLとデザインをそのまま管理画面の土台に使用
・ゲームタイトルをタップすると通常と同じ商品詳細ポップアップを表示
・各商品の詳細下部に「編集」ボタンを追加
・編集ボタンから商品タイトル、詳細、金額、状態、並び順、画像URLを変更
・商品一覧の一番下に「＋ 新規項目を追加」を設置
・新規追加時は、開いているゲームのcategoryを自動設定
・販売中、売り切れ、非表示の商品を管理画面ではすべて表示
・完全削除は確認画面付き
・変更結果をproducts.jsonとして保存可能
・公開サイト確認ボタンを追加

【管理画面URL】
http://192.168.11.17/admin/

【公開サイトURL】
http://192.168.11.17/

公開URLおよびGitHub PagesのURLに変更はありません。

【Win7 IISへの設置】
V0.5修正版フォルダの中身を
C:\inetpub\wwwroot\
へ上書きコピーしてください。

今回の主な追加ファイル:
C:\inetpub\wwwroot\admin\index.html
C:\inetpub\wwwroot\admin\admin-data-loader.js

【操作手順】
1. http://192.168.11.17/admin/ を開く
2. 編集したいゲームタイトルをタップ
3. 商品詳細ポップアップ内の「編集」をタップ
4. 内容を変更し「変更を反映」
5. 新しい商品は商品一覧最下部の「＋ 新規項目を追加」
6. 全体確認後、画面上部の「products.json保存」
7. 保存されたproducts.jsonを C:\inetpub\wwwroot\data\products.json に上書き

【現在の保存方式】
V0.5修正版ではブラウザからproducts.jsonをダウンロードします。
IIS上のJSONへ直接書き込む機能は、サーバー側保存処理を追加する次工程で実装します。
